# GitHub Explorer

A React app to search any GitHub user and view their profile stats and top repositories.

**Live Demo:** https://sharjeel-ashraf1.github.io/github-explorer/
---

## How to Use

1. Open the live link above
2. Type any GitHub username in the search bar (e.g torvalds )
3. Hit Search
4. View their profile, followers, repos and stats

---

## How to Run Locally

Make sure you have Node.js installed.

1. Clone the repository:

   ```
   git clone https://github.com/sharjeel-ashraf1/github-explorer.git
   ```

2. Navigate to the project folder:

   ```
   cd github-explorer
   ```

3. Install dependencies:

   ```
   npm install
   ```

4. Start the development server:

   ```
   npm run dev
   ```

5. Open your browser and go to:

   ```
   http://localhost:5173
   ```

---

## How to Download

1. Go to the repository on GitHub
2. Click the green **Code** button
3. Click **Download ZIP**
4. Extract the folder
5. Open terminal inside the extracted folder
6. Follow the "How to Run Locally" steps above
